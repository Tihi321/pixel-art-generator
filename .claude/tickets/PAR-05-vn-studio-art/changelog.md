# Changelog

## 2026-10-15: PAR-05, Pixel Studio for VN Studio (VNO-02 section B)

Pixel Studio now runs without a window, converts images to clean pixel art, exports PNGs at an exact size, and supports a save-back round trip. Nothing is committed yet.

**Repo:** pixel-art-generator. **Branch:** `PAR-05_vn-studio-art`, cut from `origin/master` @ 3f2cf19. **Contract:** `visual-novels-orchestrator/.claude/tickets/VNO-02-chiptune-and-pixel-studio/contracts.md` ("Common rules" and "Pixel Studio").

### Headless architecture

Tools run in the Electron main process, not in a hidden window. `src/main/toolBridge.ts` only exists to reach the renderer's live `EditorSession`; the session, the tool registry and the core are pure TS, and `ToolServices` already had a Node implementation. So `--mcp-only` builds a `DocumentSet` (several sessions) and runs `createToolHost(registry, ...)` directly. No window, no IPC hop, no readiness wait.

### Deviations from the contract
- **Formats:** PNG always; JPEG through Electron's decoder (window and headless). WebP is not decoded (`nativeImage` does not support it), and plain Node (tests) reads PNG only. The error says so.
- **`documentId`:** `docN` in headless mode, the tab id (`tabN`) in window mode.
- **Headless bind failure:** exits with code 1 and an error on stderr (the contract only specifies window mode).
- **Headless settings:** ignores `~/PixelStudio/config/mcp.json`; port comes from `--port` or `PIXEL_STUDIO_MCP_PORT`, token from `PIXEL_STUDIO_MCP_TOKEN`.
- **`export_png`:** `width` or `height` alone is allowed (aspect kept), beyond "both given".
- **`open_document` result `path`:** the PNG path for a PNG, the resolved `.pxs` path for a project.
- **Window mode while the chat agent works in the active tab:** a document added by a tool replaces that tab's document (undoable) instead of opening a new tab.
- **Headless:** the first added document replaces the untouched blank starting document.
- **`--open` passing values:** both `--open=<path>` and `--open <path>` work, including when forwarded to a running instance.
